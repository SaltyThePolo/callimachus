# Contributing

Contributions are accepted under AGPL-3.0-only; see [LICENSE](LICENSE).

Before a pull request can be merged, contributors must sign a Contributor
License Agreement (CLA) granting the copyright holder, Mattia Riviera, the rights
needed to relicense their contributions, including under a separate commercial
license.
