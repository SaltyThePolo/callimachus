# Callimachus Implementation Plan

**Goal:** Deliver a runnable meeting archiver with direct Google Drive support.
**Architecture:** Read-only Wispr source → immutable local revisions → optional Drive delivery. CLI owns authentication, configuration, locking and polling.
**Tech Stack:** Python 3.11+, official MCP and Google API SDKs, pytest, uv.
**Spec:** ../specs/2026-09-19-archive-design.md

## Global constraints

No private meeting data or credentials in Git. No invented Wispr audio endpoint. Drive API is the selected cloud destination. Existing archives survive source deletion. Runtime files are excluded from Git.

## Execution

- [x] Archive model and store (`models.py`, `archive.py`, `tests/test_archive.py`): first test partial metadata, stable revisions, audio attachment, and interrupted writes; run pytest to see missing implementation; implement atomic immutable storage; rerun.
- [x] Wispr reader (`wispr.py`, `tests/test_wispr.py`): test list pagination, finalized filtering, bounded content/transcript reconstruction and nonadvancing cursors with synthetic observed response shapes; implement; rerun.
- [x] Authentication (`auth.py`, `tests/test_auth.py`): test private token persistence and loopback callback state validation; implement SDK OAuth with explicit interactive login and noninteractive sync refresh; rerun.
- [x] Drive delivery (`drive.py`, `tests/test_drive.py`): test retries reuse uploaded files and latest manifest is last; implement scoped desktop OAuth and resumable uploads; rerun.
- [x] CLI (`config.py`, `cli.py`, `tests/test_cli.py`): test configuration errors, offline fixture sync and repeated runs; implement commands, lock and poll loop; rerun.
- [x] Publish: update README, dotenv and CI; run pytest, lint, build and installed-CLI smoke check; update GitHub map and synchronize commits.


## Verification results

33 synthetic-data tests pass, including OAuth callback state, revoked-token recovery, page reconstruction, immutable local revisions, Drive retry/manifest ordering, historical replay, lock release, and rejection of extra files/symlinks. Ruff checks and formatting pass. Source and wheel distributions build. The installed CLI completed two identical offline imports with one revision.

Standalone Wispr OAuth and live Drive delivery require the user's account configuration and remain explicitly unverified. Original audio retrieval from Wispr is not supported by the observed MCP catalog; supplied local audio can be archived.
